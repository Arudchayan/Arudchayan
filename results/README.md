# Results

Every file in this directory is generated by the CLI and committed so the
README, paper, dashboard, and GitHub Pages site can be reproduced without
rerunning the experiments.

| File | Produced by | Contents |
| --- | --- | --- |
| `leaderboard.json` | `python -m pokerl bench` | Bradley–Terry standings, every side-swapped match, config metadata |
| `training.json` | `python -m pokerl train` | BC / MLP / DAgger / RL budgets, losses, evaluation win rates |
| `learning_curve.json` | `python -m pokerl train` | Sample-efficiency series for BC and REINFORCE |
| `generalization.json` | `python -m pokerl generalize` | Train-species vs held-out-species win rates |
| `oracle.json` | `python -m pokerl eval --agent search-2 ...` | Strong-search reference match |
| `metadata.json` | `python -m pokerl bench` | Git SHA, Python version, platform, seed, config hash |
| `REPORT.md` | `python -m pokerl report` | Human-readable report assembled from the JSON |
| `run.log` | `experiments/run_all.py` | Full reference-run transcript |

Do not hand-edit these files. Change the engine or protocol, rerun the reference
pipeline, and let the report generator rewrite the tables and figures.
