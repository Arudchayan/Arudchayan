# Legacy: the daily trainer profile

This folder preserves the original **Pokémon Trainer Profile** generator that
started this repository: a GitHub Action that rebuilt a README trainer card each
day from PokéAPI data, with a deterministic archetype rotation, animated sprites,
stat bars, and a small gym-challenge issue workflow.

It was fun, but the live PokéAPI dependency made the profile silently degrade to
fallback data (all Pokémon became `NORMAL`, BST 600, `???` sprites) whenever the
API was unreachable. The current repository replaces it with **PokéLab**, an
offline, deterministic battle benchmark that has no network dependency at all.

The legacy runtime is still in `scripts/` and `data/`:

- `scripts/build_readme.py` — PokéAPI profile generator (requires network)
- `scripts/process_challenge.py` — issue-triggered gym battle
- `data/archetypes.json` — the original six trainer teams
- `data/move_cache.json` — cached move metadata

The current README is **not** generated by this code. See the top-level
[README](../README.md) for the research benchmark and `python -m pokerl` for the
daily lab dispatch.
